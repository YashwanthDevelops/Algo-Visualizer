Fundamentals of Artificial Intelligence03 / 10
AlgoAIHow the system works

System architecture

Independent computation. Inspectable recorded decisions.

1. Configure a problem in the browser.2. A Web Worker validates and executes the algorithm.3. States, reasons, pseudocode lines, and metrics are recorded.4. Playback restores recorded states; rendering stays on the main thread.5. Store inputs and summaries; compare copies of the same problem.

HTML · CSS · JavaScript modules · SVG · Web Workers · LocalStorage
